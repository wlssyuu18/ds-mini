# ESS 배터리 수명 예측

초기 100 사이클의 방전 전압 및 용량 열화 데이터를 기반으로 배터리가 EOL(방전 용량 80% 도달 시점)에 도달하기까지의 Cycle Life를 조기 예측하는 머신러닝 파이프라인 구축

- **BESS 운영사**: 조기 이상 셀 식별을 통한 사전 점검 및 예방적 팩 교체 스케줄링으로 불시 시스템 중단 방지
- **배터리 제조사**: 수천 사이클에 달하는 장기 수명 평가 소요 시간을 초기 100 사이클로 단축하여 품질 검수 기간 단축 및 출하 선별 효율화에 활용

---

## 프로젝트 개요
- **데이터셋**: MIT-Stanford Battery Dataset (Severson et al., *Nature Energy* 2019)
- **학습 데이터**: Batch 1 (2017-05-12, 유효 표본 46개)
  - Train: 35개 셀 (18개 충전 프로토콜)
  - Hold-out Valid: 11개 셀 (5개 충전 프로토콜, 프로토콜 중복 누수 차단)
- **평가 데이터**: Batch 2 (2018-02-20, 유효 표본 39개)
- **태스크**: Regression (연속형 `cycle_life` 예측)
- **목표 성능**: 원논문 벤치마크 MAPE 9.1%

## EDA 핵심 발견

1. **Cycle Life 분포 및 배치 이동 (Q1)**
   - Batch 1(중앙값 858.5) 대비 Batch 2(중앙값 472.0)는 500 사이클 미만 단수명 셀이 71.8%를 차지하는 현저한 Target Shift 관찰
   - 핵심 발견: 단순 무작위 분할 대신 배치 단위 격리 평가 유지 및 연속형 회귀(Regression) 태스크 채택

2. **열화 곡선 및 Knee Point 분석 (Q2)**
   - 초기에는 선형적으로 완만하게 감소하다가 전체 수명의 75~79% 지점(Knee Point)에서 급격한 가속 열화 구간 진입 확인
   - 핵심 발견: Knee Point는 사후 지표이므로 조기 예측 입력에서 배제하고 초기 100 사이클 신호에 집중

3. **ΔQ(V) 전압 차이 곡선 분석 (Q3)**
   - 사이클 100과 사이클 10의 방전 전압별 용량 차이 곡선($Q_{100}(V) - Q_{10}(V)$)에서 단수명 셀일수록 음의 피크 골이 깊고 분산 폭이 큼을 확인
   - 핵심 발견: $\log_{10}(\text{var}(\Delta Q))$ 신호가 3개 배치에서 일관되게 강한 관계를 보인 핵심 단일 신호로 작용

4. **충전 속도(C-rate)와 수명의 관계 (Q4)**
   - 첫 충전 C-rate 크기와 수명 간 음의 상관관계는 배치별로 일관되지 않음(Batch 1: -0.48, Batch 2: +0.06)
   - 핵심 발견: 충전 속도 단독 해석을 지양하고 충전 제어 파라미터(`first_C_rate`, `switch_SOC`, `second_C_rate`)로 물리 분해

5. **상관관계 및 다중공선성 분석 (Q5)**
   - `delta_q_var`는 3개 배치 전반에서 $-0.70 \sim -0.87$의 강하고 일관된 음의 상관관계를 유지한 핵심 지표
   - 핵심 발견: `delta_q_min`과의 극단적 다중공선성($|\rho| \approx 0.985$) 및 온도·충전시간의 배치 간 부호 역전을 확인하여 단일 핵심 신호 중심 모델링 수립

## Modeling

### 피처 엔지니어링 전략
- **스케일링 누수 배제 원칙**: Feature Engineering 단계에서는 `StandardScaler` 등 데이터 스케일링을 사전 수행하지 않고 원본(Raw) 상태로 저장
- **Hold-out 충전 프로토콜 분할**: 동일 충전 정책 셀이 Train과 Valid에 나뉘어 들어가는 누수를 차단하기 위해 정책 단위의 독립 분할 수행
- **점진적 피처 실험 (Ablation)**:
  - Set A: `log_delta_q_var` (Train CV MAPE 7.08%, CV Std 0.98%, Valid 12.72%)
  - ALT: `delta_q_min` (Train CV MAPE 8.89%, CV Std 1.98%, Valid 9.41%)
  - Set B~E (다변수): 보조 물리 변수 추가 시 CV 또는 Hold-out 성능이 악화되어 소표본 환경(N=35)에서의 일반화 이점이 제한적임을 확인하고 미채택

### 모델 선택 및 근거
- **후보 모델**: Ridge, ElasticNet
- **추가 실험**: Ridge alpha 튜닝(0.01~100), Raw Target vs Log Target 비교
- **최종 모델**: `Pipeline([SimpleImputer, StandardScaler, Ridge(alpha=1.0)])` + **Set A**
- **선택 이유**:
  - ALT는 Hold-out Valid MAPE(9.41%)가 더 우수했으나, 단일 Hold-out 분할 결과보다 GroupKFold 교차검증 평균 성능(7.08%)과 폴드 간 낮은 변동성(Std 0.98%)을 우선하여 Set A를 최종 피처로 선정
  - 단일 물리 신호 기반 환경에서 ElasticNet 적용 시 Ridge 대비 뚜렷한 성능 개선이 확인되지 않았으며, Log Target 적용 시 Valid MAPE가 17.40%로 악화되어 단순 선형 관계를 유지하는 Raw Target Ridge 최종 확정

## ESS 도메인 해석

- **BESS 운영 의사결정 활용 방안**:
  - 배터리 설치 초기 100 사이클 데이터를 통해 셀의 예상 EOL 시점 및 Cycle Life를 조기 진단하고 셀/모듈 점검 및 BESS 정비·교체 계획 수립을 지원
  - `log_delta_q_var`와 같은 초기 열화 신호를 조기 스크리닝 지표 후보로 활용
- **모델의 한계점 및 실 배포 고려사항**:
  - 단수명 셀의 수명을 과대평가할 경우 예방정비 시점을 놓쳐 배터리 팩 가용 용량 저하 및 교체 일정 차질 유발 위험 잔존
  - 실 BESS 배포 시에는 단일 점추정값에만 의존하지 않고, 추가 검증 데이터를 기반으로 예측 불확실성을 평가하고 보수적인 정비 기준을 병행 수립할 필요
